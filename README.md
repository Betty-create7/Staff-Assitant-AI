# NITDA Staff Assistant AI (Unified Productivity Dashboard)

## Overview
A high-performance backend API for a centralized productivity dashboard. This project aggregates multiple daily tools into a single workspace, leveraging AI to intelligently summarize emails, prioritize tasks, and track deadlines.

## Features
* **AI-Powered Email Summarization:** Integrates with the OpenAI API to automatically read, analyze, and summarize long email threads.
* **Priority Organization:** Categorizes incoming emails and notifications based on user-defined priority levels.
* **Deadline Tracking:** Monitors tasks and triggers notifications for time-sensitive deadlines.
* **Secure Configuration:** Utilizes `.env` files to securely manage sensitive OpenAI API keys.

## Tech Stack
* **Backend Framework:** Python (FastAPI)
* **AI Integration:** OpenAI API
* **Data Validation:** Pydantic
* **Tools:** python-dotenv, Uvicorn
